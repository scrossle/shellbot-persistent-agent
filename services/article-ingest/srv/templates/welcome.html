Article Ingest Webhook

Persistent HTTPS endpoint for syndicating articles into daily research logs

What This Service Does

This is a specialized webhook that accepts articles from external sources (IFTTT, mobile apps, RSS feeds) and ingests them into your agent's daily log.

Process:
  1. Authenticate via API token (query parameter)
  2. Fetch the article using full-text extraction
  3. Synthesize via LLM (2-3 sentence summary)
  4. Detect connections to active research threads
  5. Append to today's daily log with research tags

API Endpoint

POST /ingest?token=<YOUR_TOKEN> Content-Type: application/json {"url": "https://example.com/article"}

Response (success):

{"status":"success","message":"article ingested and appended to daily log","title":"...","appended":true}

Security

  • API Token: 256-bit random token (required query parameter)
  • Rate Limiting: 1 request/second per IP, burst of 5
  • SSRF Protection: Rejects localhost, private IPs, file:// schemes
  • Input Validation: URL format checking, 10MB response limit

IFTTT Configuration

Create a new applet:

  • If This: Choose trigger (Pocket, Gmail, RSS, etc.)
  • Then That: Webhooks → Make a web request
  • URL: https://shellbot.exe.xyz/ingest?token=<YOUR_TOKEN>
  • Method: POST
  • Content Type: application/json
  • Body: {"url": "<>"}

Daily Log Format

Ingested articles appear in your daily log as:

## Shaun shared — HH:MM [LLM synthesis of article content] *Relates to: [Research thread if matched]*
Note: This service connects to the persistent agent system. Articles are synthesized via the exe.dev LLM gateway and tagged with active research threads from your long-term memory. See the persistent-agent README for full system documentation.
